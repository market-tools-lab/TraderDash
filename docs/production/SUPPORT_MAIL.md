# Supportmail

Dato: 9. november 2026. Bekræftet samme dag.

`support@markettools.app` er i drift gennem Cloudflare Email Routing. En prøvemail udefra blev modtaget. Den private modtagerpostkasse står ikke her.

`noreply@auth.markettools.app` er kun afsender for Auth-mail gennem Resend. Den er ikke ændret og må ikke bruges som supportadresse.

Ruten kan slås fra hos Cloudflare. Auth-afsenderen bliver stående. Denne note ændrer ikke DNS eller Resend.
